# Credits & Attribution

**Forbidden USB Stick Games** is an offline game **launcher/hub**. The hub itself
(`.hub/` pages, the launcher, the motion layer, etc.) was built for this project.
**None of the games belong to this project.**

## Third-party game sources

The playable corpus in `.games/` is a compilation of freely available HTML5 /
WebGL / Flash-port browser games, assembled for offline preservation. The primary
source collection is:

- **Offline-HTML-Games-Pack** — https://github.com/CoolDude2349/Offline-HTML-Games-Pack
  (~352 single-file offline HTML games). Games from this pack remain under whatever
  terms that repository and their original creators set.

Additional titles were collected from other public HTML5 game sources and
single-file game packs. Where a game ships its own credits, licence or home-page
link, those files are preserved untouched inside the game's own folder.

## Ownership

All game titles, code, art, audio and trademarks remain the property of their
respective creators, developers and publishers. They are included here **without
any claim of ownership**, for personal offline use and preservation only.
Inclusion is **not** an endorsement, and this project claims **no affiliation**
with any game or its creators.

If you are a rights holder and would like a title removed, open an issue in the
repository and it will be removed promptly.

are the work of the Eaglercraft project and its contributors. *Minecraft* is a
trademark of Mojang Synergies AB / Microsoft. This project is not affiliated with
